# Proustite Prism

Full-colour Python 3 neon ruby-silver refractor arcade for ElbowOS.

Spin a hexagonal prism so the exit beam kisses a matching gem. Ruby, amber, and violet beams cycle as the streak climbs. A wrong colour cracks the streak.

Left / Right (or A / D) rotate. Space pulses a wider catch. R restarts.

## Play

```
pip install -r requirements.txt
python3 proustite_prism.py --play
```

## Record a 9:16 reel

```
python3 proustite_prism.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
